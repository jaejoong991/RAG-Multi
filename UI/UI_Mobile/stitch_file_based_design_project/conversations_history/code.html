How can I integrate the vector database with my existing S3 buckets for real-time indexing?
USER • 14:20:12

To integrate your vector database with Amazon S3 for real-time indexing, you should follow these three primary steps:

  1. Configure an S3 Event Notification to trigger on all `ObjectCreated` events.
  2. Point the notification to a Lambda Function that handles the document extraction and embedding.
  3. Upsert the generated vectors into your Knowledge OS namespace using the `/v1/upsert` endpoint.

Is there a limit on the file size for real-time indexing via this method?
USER • 14:21:05

The file size limit is primarily dictated by the memory limits of your Lambda function (up to 10GB) and the maximum payload size of the Knowledge OS ingestion API (currently 50MB per request). For larger files, we recommend pre-processing and chunking them before sending them to the indexing service.
