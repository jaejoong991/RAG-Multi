Common Troubleshooting

Encountering issues with the initialization? Here are the most common solutions.

Widget not appearing in the bottom right? expand_more

Ensure your `widgetId` matches the one provided in the configuration block. Also check if your domain is whitelisted in the 'Security & CORS' settings.

Content Security Policy (CSP) errors? expand_more

You need to add `cdn.rag-platform.com` and `api.rag-platform.com` to your `script-src` and `connect-src` directives respectively.

How to trigger the widget programmatically? expand_more

Use `window.rag.open()` or `window.rag.close()` after the script has successfully loaded.
