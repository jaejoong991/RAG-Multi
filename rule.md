
# Project Management Rules

In this project, we maintain high engineering standards by following these management rules:

1.  **QA Engineering**: Every feature or bug fix must have associated testing cases. We maintain a `TESTING.md` file that lists all manual and automated test scenarios, edge cases, and verification steps.
2.  **Task Management**: We maintain a granular `TASKS.md` file to track project progress. Every high-level goal from `plan.md` is broken down into actionable sub-tasks with status tracking.
3.  **Proactive Validation**: Before completing any task, the AI agent must verify the changes against the `TESTING.md` criteria.
